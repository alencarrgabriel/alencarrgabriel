## Projetos em Destaque

### [Mão Na Roda](https://github.com/alencarrgabriel/mao-na-roda-bot-ts) — Chatbot WhatsApp · **Em produção, gerando receita**

> Consulta veicular via WhatsApp com funil de vendas e pagamento PIX integrado.

- Funil completo: consulta gratuita → upsell → cobrança PIX → entrega automática de PDF
- Integração Z-API (WhatsApp), OpenPix (PIX) e APIs de dados veiculares
- Sessões com expiração, debounce de webhooks duplicados e fila de retry com Redis
- Painel admin com métricas de funil, receita e logs em tempo real
- Deploy em VPS Linux com Docker Compose + Caddy (HTTPS automático) + Sentry

**Stack:** `TypeScript` `Node.js` `Express` `Prisma` `PostgreSQL` `Redis` `Docker` `Caddy` `Z-API` `OpenPix`

### MargemReal — Motor de Landed Cost · **Em produção**

> Plataforma SaaS para cálculo de custo de importação China-Brasil, incluindo fretes, impostos e taxas alfandegárias.

- Motor de cálculo de Landed Cost com múltiplos regimes tributários
- API em FastAPI com autenticação e multi-tenant
- Frontend em Next.js com simulador interativo
- Deploy containerizado na Hetzner

**Stack:** `Python` `FastAPI` `Next.js` `PostgreSQL` `Docker`

### Lunna · **Beta**

- API modular em NestJS com Prisma ORM

**Stack:** `NestJS` `Next.js 15` `TypeScript` `PostgreSQL` `Prisma` `Docker`

### [InteraEdu](https://github.com/alencarrgabriel/intera_edu) — Rede Social Acadêmica

> Rede social exclusiva para universitários, com verificação por e-mail institucional.

- App Flutter 3 com Clean Architecture, BLoC e suporte Android/Web/iOS
- Backend NestJS 10 com TypeORM e autenticação JWT
- Object storage com MinIO (S3-compatible) para mídia
- Infra containerizada: Node 20, PostgreSQL 16, Redis 7, MinIO

**Stack:** `Flutter` `Dart` `NestJS` `TypeORM` `PostgreSQL` `Redis` `MinIO` `Docker`

### Feliz no Simples — App Mobile + Backend

> Plataforma mobile com busca geoespacial, chat em tempo real e CI/CD automatizado.

- Flutter com BLoC e GetIt (injeção de dependência)
- NestJS com Firebase Auth (Google/Apple), JWT e PostGIS para geolocalização
- Chat em tempo real com Socket.IO + Redis

**Stack:** `Flutter` `NestJS` `PostgreSQL` `PostGIS` `Socket.IO` `Firebase` `GitHub Actions`

### [Gerador de Recibos](https://github.com/alencarrgabriel/GeradorRecibos) — App Desktop · **Usado por empresa**
